# 代理任务与数据用途

`proxy-v1` 是规则标注的结构化文本分类任务，不是驾驶安全验证。输入包含车速、限速、前车距离、信号灯、行人、封闭车道和能见度；输出为行为、速度档、是否让行。单位为 m、m/s。

`driveserve/task.py::validate_scene` 是可执行 schema：字段必须齐全、禁止额外字段，数值必须有限且在声明范围内，布尔字段不接受 0/1 替代。`label` 的规则优先级为 stop → slow → proceed。阈值是自建代理任务定义，不宣称来自交通法规或真实制动模型。限速当前仅作为场景上下文，输出不包含可执行的速度指令。

评分器严格解析一个 JSON 对象，拒绝重复键、缺失/额外字段、NaN、类型错误和 Markdown 包装。报告 JSON 有效率、三个字段准确率及全字段匹配；独立规则标签不依赖教师生成。规则 oracle Demo 只检查数据接口，不能成为模型质量或吞吐结果。

当前样本 `data/samples/proxy-v1.jsonl` 共 128 条、32 个场景组，每组四个变体；train/calibration/dev/test 各 32 条。seed、hash 与构造参数见同名 manifest。场景组不得跨 split，拒绝重复 ID 和相同场景内容。模板和任务规则跨 split 共享，因此不宣称跨任务或真实道路泛化。

| 用途 | 当前资源 | 后续冻结条件 |
|---|---|---|
| 性能与压力 | dev 场景用于客户端冒烟 | 增加短/长/混合、热点与一次性请求、长输出合成负载，冻结 tokenizer 长度与到达轨迹；业务与合成压力分开 |
| 质量 | 独立规则标签与评分器 | 当前 test 只是开发 fixture；正式测试集另建版本并冻结，禁止用最终测试调参 |
| AWQ 领域校准 | calibration split 的构造入口 | 按实际 token 预算扩展，保持与测试组隔离；通用校准语料尚未选定/下载 |
| Draft 蒸馏 | train/dev split 的构造入口 | 待教师真实生成并训练，保存生成参数、过滤、训练日志和 checkpoint；不能把规则 oracle 称为教师模型生成 |

当前数据均自建，无外部数据集许可依赖。模型许可独立记录，不能把权重默认视为可自由再分发。任何最终测试与评分规则变化必须新建版本并重跑受影响对照。
