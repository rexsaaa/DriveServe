## 资源与主要风险

- 源码、配置、依赖锁、数据manifest、小型日志和原始Nsight报告进GitHub；模型与环境本体放项目专属OSS目录，逐包回读。当前实例的/hy-netdisk实际为overlay，仍不视为可任意迁移的挂载。
- GPU推理环境固定torch2.6.0+cu124/vLLM0.8.5，系统nvcc12.1。切换机器先检查驱动/架构，再重建扩展和服务回归；未实际换机，未声称24GB卡通过。
- GPU基础配置以24GiB内的运行占用为目标。固定K的0.45显存比例仍超过24GiB，0.40的15次采样为22762–22826MiB；比例不是硬上限，真实24GB卡须重算与复测。
- 拓扑NODE、没有NVLink，TP2原生P2P检查失败。通信收益须实测，双副本与TP2按同样两卡资源比较，单卡单独作为资源效率参考。
- 本机临时盘50GiB、overlay30GiB，比OSS更容易成为限制。模型、环境、训练checkpoint和量化导出先算本地峰值；只有确认云端副本和恢复校验后，才考虑轮换可再生成的项目临时文件。不删除既有云资产或唯一副本。
- 按平台截图0.0004元/GB/小时记录OSS估算费用。27.024GB模型约0.2594元/天；环境快照约0.03965元/天，合计约0.2991元/天。没有采用旧30GB上限，也没有承诺其他付费资源。

## 长任务和资产周期

命令包装器30秒保存心跳和进程指纹；模型OSS每包读回后原子更新收据；环境快照完成归档后保存SHA，读回逐成员验证后保存完成收据。新训练类型引入时落实5分钟状态、15分钟或epoch完整checkpoint，并实际中断续训验证。CPU恢复演练不能代替训练续训。

备份及实验按工作单元触发；尚未部署定时后台同步、平台自动开机或agent自动唤醒。恢复时先核验进程身份与现有产物，沿用相同任务state，避免重复训练或创建重复收费副本。若出现新增算力费用、无法满足六线要求或需要改变模型家族/范围，提交已有证据和具体可选方案；常规实现、检查、Git提交和已授权OSS留存继续自主执行。
