# 个人学习记录

在这里新建 Markdown 笔记并提交到 `interview-practice`，可随下次 clone 迁移。当前进度仍以[学习交接](../learning-handoff-2026-10-26.md)为准，本目录的建立不表示完成了新的练习。

每次记录日期、M/R 编号、自己的回答或执行命令、实际 run 路径与代码 SHA、观察结果和待补问题。区分本人操作、助手演示、只阅读报告三种情况。

新实验原始输出仍保存在 `experiments/runs/`；该目录的新文件被忽略，需要保留时只显式提交经过核查的 manifest、日志和必要结果。模型与环境等大资产沿用[资产恢复说明](../../assets.md)。
