# DriveServe

面向结构化车载决策**代理任务**的 vLLM 推理优化实验项目。它不是真实车辆的感知—规划—控制系统。

当前处于 **S1 基础建设，尚未验收**。没有已发布阶段、六线完整实现或性能收益结论。原始规范中的百分比是目标占位值。
